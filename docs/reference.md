# 快捷键与设置参考

## 常用操作

| 位置 | 操作 |
| --- | --- |
| 任意目标输入框 | 默认按住 Fn 录音，松开完成；切换式行为以输入设置为准 |
| 主窗口 | ⌘F 打开或重新聚焦统一搜索 |
| App | ⌘, 打开独立设置窗口 |
| 搜索结果 | 方向键选择，Return 定位结果，Esc 退出 |
| 快捷面板 | 方向键选择，Return 粘贴，⌘1…9 投递对应可见结果 |
| 快捷面板预览或弹窗 | Esc 先关闭当前层，再退出面板 |

主窗口搜索的 Return 用于导航；快捷面板的 Return 用于粘贴。
中文组合输入时，先完成输入法选词。面板唤起快捷键可在“输入”中配置。

## 设置位置

| 分区 | 内容 |
| --- | --- |
| 常规 | 界面语言 |
| 输入 | Fn 行为、输出方式、剪贴板采集和面板快捷键 |
| 语音与模型 | 识别/合成模型、LLM 与 Jev API、语音助手资源 |
| 词汇与记忆 | 词汇映射、热词、上下文纠错与长期记忆 |
| 隐私 | 系统权限、敏感应用、云端与预览策略 |
| 数据 | 留存、分类清理、恢复与诊断 |

全局搜索可以定位设置分区；Jev API 密钥和润色判断有具体控件入口。
打开设置不改变主窗口的记录选择。
