# Rill 输入法

Rill 输入法使用 Rime，作为独立的 macOS 输入源运行。退出 Rill 主程序后仍可打字；
语音输入和剪贴板采集无需开启输入法。默认使用随安装包提供的轻量简体全拼词库，
不包含万象或 LTS 语言模型，也不需要安装鼠须管。

## 首次安装

1. 打开 Rill 的“设置 → 输入 → 输入法”。
2. 选择“安装 Rill 输入法”。安装使用包内词库，无需联网，也不会读取个人鼠须管目录。
3. 打开系统设置的“键盘 → 文字输入”，添加 Rill 输入源。
4. 切换到 Rill 后，在空白文档中输入拼音并选择候选。新输入源未出现时，macOS 可能需要注销后重新登录。

安装前需停止正在运行的 Rill 输入法。安装程序拒绝覆盖已有的 Rill 输入法或配置；
它不会自动合并、更新或删除现有数据。输入源切换始终由用户操作。

## 可选：首次从鼠须管导入

导入是首次安装时的另一条路径。已有 Rill 配置时不能借此覆盖安装。

1. 切换到 ABC 输入源，退出鼠须管和 Rill 输入法。
2. 选择“从鼠须管导入并安装…”，指定自己的 `~/Library/Rime` 目录。
3. 安装程序复制并核对完整配置，包括方案、Lua、模型和 userdb；缺失的标准 OpenCC 数据从 Rill 包内补齐。

原目录保持不变，个人自定义文件优先于随包提供的标准资源。导入后不再读取原目录，
也不会自动同步两个输入法的后续变化。首次验收建议直接使用默认配置。

## 从打字生成词汇建议

此功能默认关闭，允许的应用列表默认为空。开启“从打字生成词汇建议”后，还需要明确选择
允许学习的应用；现有隐私规则仍然适用。关闭授权或连接断开后，不再使用旧学习策略，
重新连接也不重放丢弃的内容。

只有经你确认的建议才会加入现有个人词汇集合，供后续适用的语音请求使用。可以忽略、删除或清空建议。
撤销确认只删除该建议创建的词汇；此前已有的词汇不会随之删除。功能不保存连续打字全文。
词汇成功传递并不代表识别准确率已经提高。

学习连接要求主程序与输入法由同一个 Apple 开发者团队签名。临时签名的开发包仍可打字，
但学习连接不可用；这类构建不能用于验证学习连接成功的场景。

## 数据与排查

输入法安装在 `~/Library/Input Methods/RillInputMethod.app`，独立配置位于
`~/Library/Application Support/Rill/InputMethod/`。仅退出主程序不会停止输入法或删除这些数据。

需要退回其他输入法时，先在系统输入菜单中选择它。移走 Rill 输入法或配置前，应先停止
Rill 输入法；不要在它运行时维护词库数据库。不要通过反复覆盖安装处理已有配置。

依赖来源与许可见[输入法依赖](input-method-dependencies.md)。构建和工程验证见仓库的
[维护说明](https://github.com/zrr1999/rill/blob/main/docs/input-method-development.md)。
