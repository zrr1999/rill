# Rill UI 方向：内容检索与原生 macOS 工作站

设计基准为 Apple Human Interface Guidelines；Raycast 只用于快捷面板的搜索、键盘操作与内容预览参考。

本文是维护中的界面与交互契约。macOS 26 是最低版本；实现以现有 SwiftUI/AppKit
界面为基础，保留已有效的结构和使用习惯，系统导航与必要浮层采用 Liquid Glass。
正文、预览和编辑内容保持稳定不透明。品牌图标及文档站框架保持既有设计。

本轮视觉方向已于 2026-09-28 确认，包括主要入口同组置顶、合并快捷面板与待发编辑、
可收起的常驻待发条，以及保留现有录音浮窗。具体实现与验证结果写在 PR 和验收记录，
视觉确认不代表原生交互验收通过。继续复用现有状态所有者，不增加内容副本或数据迁移。

## 信息架构

语音输入是产品主线，工作流是可复用的辅助配置；用户不需要先理解工作流就能完成语音输入。

主窗口围绕“找回和复用内容”组织，默认进入全部记录。侧栏顶部同一组依次是全部记录、活动、工作流，之后是记录集，底部设置入口打开独立窗口。听写循环仍由字幕浮层、菜单栏与快捷面板承担。

- 全部记录是 RecordStore 的去重视图，选择该入口不隐式选中第一个集合。
- 记录采用导航、列表、详情分栏。列表展示摘要、来源与时间；详情优先展示内容与复制，集合归属与元数据放在详情披露中。集合策略进入集合设置，采集与投递规则在独立管理入口中。
- 内容区不足 700pt 时在列表与详情之间切换；默认主窗口仍为 960×720，支持调整分栏宽度。
- 主窗口首次准备不足时呈现可跳过的准备面板，只展示 VoiceSetupReadiness 的缺失条件；关闭后本次会话保留工具栏恢复入口，不因异步刷新反复弹出。
- 活动页突出待处理选择、失败恢复和进行中状态；成功运行使用紧凑行，展开后保留完整回执、纠错、隐私预览及失败录音恢复。精确阶段耗时只显示已记录的数据，旧数据的时间区间不推算为精确时间。
- 工作流采用列表与说明详情，依次展示用途、触发方式、输出和启用状态，处理步骤按需展开。外部 TOML 编辑、导入、复制、恢复预设与删除仍沿用原有行为。

运行行只保留一份标题、状态和时间；收起时显示正文预览，展开时原位显示正文与紧凑的阶段耗时。键盘与辅助功能焦点落在展开按钮上，不包住整块详情。

单次运行的“执行详情与诊断”按 run ID 查询最近 20 条已清洗事件，失败操作直接展开当前运行的诊断。默认显示警告与错误，其他日志通过“显示全部”查看；每条事件用一行摘要，技术字段按需展开。录音长度来自音频，识别与润色 API 耗时来自单调时钟；未计时、旧记录缺失或未运行的步骤不补估值，失败、取消和回退保留实际消耗的调用时间。

## 统一搜索与导航

主窗口 `⌘F` 和工具栏搜索由同一浮层提供，保留 AppKit NSSearchField 桥接与首次/重复聚焦、方向键、回车、Esc 合同。页面不再提供第二套文字搜索框，置顶、来源与类型仍属于页面筛选。

结果依次为记录、记录集、运行历史、工作流、设置、页面。Record 通过现有 RecordStore.query 查询完整可搜索内容，扫描空批次并支持继续加载；运行历史沿用既有浏览服务与隐私预览权限。两类异步查询独立失败，过期查询不能更新新结果，搜索关闭即取消展示。

搜索选中 Record 后调用统一定位动作：进入全部记录、清除冲突筛选、刷新目录、选中记录并聚焦详情。记录被删除时显示不可用状态。快捷面板“在记录中显示”复用同一入口。搜索选中记录不会粘贴。

## 独立设置窗口

原生 Settings scene 提供 App 菜单和 `⌘,` 入口。设置与主窗口共享 AppModel、持久化协调和保存失败状态，不创建第二套服务或存储。

| 分区 | 内容 |
| --- | --- |
| 常规 | 界面语言 |
| 输入 | Fn 工作流、剪贴板捕获、面板快捷键 |
| 语音与模型 | 识别/合成模型、API 服务（LLM 与 Jev）、语音助手资源 |
| 词汇与记忆 | 词汇映射、上下文纠错、长期记忆管理 |
| 隐私 | 系统权限、敏感应用和预览策略 |
| 数据 | 留存、清理、恢复与诊断 |

Jev 的 TypeSafe API Key 在 API 服务中配置，仅保留到退出 App；候选比较弹窗提供直达设置的入口，继续要求发送前预览和确认。全局搜索 Jev、TypeSafe 或 LLM API 可定位到 API 服务。

六分区使用原生侧栏和分组表单；语音模型、API 服务与语音助手分别成章，模型标识与常驻选项按需展开。切换分区保留当前表单草稿，隐藏分区不接受键盘或辅助功能焦点。

设置深链携带具体设置项，映射到分区并定位；打开设置不改变主窗口的记录集、记录选择或活动导航。再次打开保留本次运行中的最后分区。

## 统一快捷面板与常驻待发

快捷面板与待发编辑共用一个非激活原生面板，顶部通过“记录集 / 待发”切换。
记录集模式保留剪贴板与其他记录集选择、搜索、结果、预览、复制、加入待发和明确输出。
待发模式复用现有列表及 NSTextView；正文、真实保存状态和发送优先，修改差异及容器策略次级。
模式切换不清空查询、选择、滚动位置、编辑和撤销历史，不触发输出；中文组合输入优先。
记录集模式 Return / ⌘1…9 输出；待发编辑 Return 换行、⌘Return 显式发送。

面板可收起为 320×56pt 的常驻条，显示数量、下一项摘要、展开及关闭。
仅遇到输出确认或错误时增加必要操作。条带可拖动、不抢键盘焦点，与录音浮窗分别呈现。
再次从外部应用唤起时，在面板激活之前捕获目标并通过现有身份校验；模式切换不改投，
常驻条不能将过期目标自动视为有效目标。保存失败保留编辑内容和重试入口。

## 环境层与视觉规则

- 紧凑字幕保持 248 × 48pt，为临近录音时限的继续按钮预留空间；计时与 Esc 键盘提示完整显示，倒计时出现时不改变窗口宽度。
- 快捷面板保留回车粘贴、复制、置顶、⌘1…9、Esc 逐层关闭。宽度达到 760pt 且预览已打开时左右分栏，窄窗口在下方预览。
- 目标应用名称来自投递控制器同一目标解析路径，目标激活与退出时更新提示；实际投递仍经过现有焦点恢复和身份校验。
- 主窗口复制复用现有 RecordReuseSubject 通道，根据实际复制结果反馈，不调用集合消费投递。
- 使用系统字体、强调色、语义背景和原生选择色。现有 4/8/12/16/20/24pt 间距与 RillRadius 继续复用；卡片用于需要行动的事项。
- 原生控件和转场优先；自定义状态变化不阻塞输入。分别适配减少动态效果、减少透明度和提高对比度；减少透明度时字幕与快捷面板使用不透明系统背景。
- 文案走 L10n 双语表；SF Symbols 复用 RillSystemSymbol。保存和复制反馈以真实结果为准。

应用与菜单栏的图标语言、状态区分和源文件维护见 [图标设计](icon-design.md)。功能图标继续使用 `RillSystemSymbol`；品牌标记以 `Resources/AppIcon` 中的 SVG 为源。菜单栏就绪态使用单色 template PDF，有记录时显示圆点；录音、权限和临时采集状态沿用系统符号。

## 验证边界

### 目标流程与布局

```text
主窗口（默认 960 × 720）
┌ 侧栏 ────────┬ 记录列表 ─────────┬ 内容 ────────────────┐
│ 全部记录      │ 摘要              │ 正文 / 图片 / 文件     │
│ 活动          │ 来源 · 时间        │ 复制                  │
│ 工作流        │ 筛选：置顶/来源/类型│ 集合归属、元数据       │
│ 记录集        │                  │                      │
└─────────────┴─────────────────┴─────────────────────┘
⌘F → 分组结果 → 定位具体记录 → 预览 → 复制
快捷面板 → 本地候选 → 比较预览 → 显式发送 → 选择候选 → 显式粘贴
                        ↓ 配置/修复
              设置具体项 → 返回比较 → 新预览 → 显式发送
```

不足 700pt 的记录内容区只显示列表或详情，返回保留选择与滚动位置；无记录时只呈现一个空态。
列表保留有效选择，内容更新不抢焦点。详情长文本可选择、滚动，图片按可用空间适配，文件
不可用时呈现原因；文件预览不能改变原始 payload 或触发外部打开。

全局搜索和快捷面板共用字面优先查询：完整字面扫描没有结果才启用近似/拼音匹配。
同一查询的后续页保留匹配模式和目录版本；版本变化重新查询，快速输入取消旧任务。
页面文字搜索不触发云服务。本地语义结果与 Jev 比较继续作为明确标识的可选入口。

设置导航采用“分区 → 章节 → 具体控件”，搜索与错误动作使用相同映射。章节的键盘与辅助功能
焦点落在可展开/收起的标题上，焦点框不包含展开后的表单内容。Jev 凭据只存在于
本次运行，共享配置状态，但候选发送与润色判断是独立授权：保存 Key 不启用开关；清除 Key
关闭润色并使进行中的旧授权失效；无效替换保留原配置并报告错误。

比较离开弹窗时只保留内存中的查询、筛选、选择与候选 ID，不保存预览正文、凭据或已确认
授权。返回按钮重新读取候选并校验当前隐私、目录和有效期；删除/隐私变化要显示原因。
关闭设置或取消返回清理这次意图。网络/限流错误允许用户重新准备预览，再次发送必须确认。

### 持续验收范围

| 优先级 | 页面与改动 | 完成标准 |
| --- | --- | --- |
| P1 | 记录详情收敛正文、复制与次级信息；统一搜索只保留一个高频入口 | 文本、图片、文件、长内容、空结果都可完成搜索到复用；不重复空态 |
| P1 | 活动页顶部仅展示进行中、阻塞与可恢复失败 | 成功记录紧凑；每个异常有原因和可执行入口；耗时来自当前运行真实计时 |
| P2 | 设置六分区稳定导航，弱化长表单和重复说明 | ⌘,、搜索和错误入口定位同一控件；保存失败可见且不谎报成功 |
| P2 | 工作流详情先解释用途、触发方式和输出 | 启用状态可读，编辑/导入/恢复移入次级操作，不暗示可视化编辑能力 |
| P2 | 菜单栏、字幕与快捷面板统一状态和操作层级 | 提示与实际投递目标一致；正常状态安静，错误可恢复，不延迟输入输出 |
| P3 | 首次使用与词汇/记忆管理整理 | 只展示当前缺失条件；区分显式映射与学习内容，保留查看来源和删除入口 |

### 状态与交互验收矩阵

| 范围 | 必须覆盖 |
| --- | --- |
| 搜索 | 字面优先、拼音/近似兜底、跨空批次分页、快速输入取消、版本变化重查、单源失败、已删除结果 |
| Jev | 初次未配置、有效替换、无效替换、清除中请求、默认关闭润色、隐私撤销、失败回退、退出清理 |
| 设置返回 | 精确控件定位、上下文保留、关闭清理、重新预览、明确二次确认；不得自动发送或粘贴 |
| 布局 | 中英文、深浅色、960×720 与紧凑窗口、长文本、文本/图片/文件、空态、失败态 |
| 键盘 | 首次及重复 ⌘F、⌘,、方向键、Return、Esc、⌘1…9；中文组合输入不误提交 |
| 辅助功能 | VoiceOver 标题与控件顺序、选择播报、焦点恢复；减少动态效果、减少透明度、提高对比度分别验证 |

模型与查询测试覆盖分页、取消、失效记录、独立设置导航和失败结果；原生 AppKit 测试覆盖焦点。UIRenderEvidenceTests 与 RecordQuickPanelRenderTests 使用临时样例数据导出渲染证据。

自动化与快照不能替代真实 Fn、IME 组合输入、跨应用粘贴、VoiceOver、多显示器和 macOS 26 交互验收。QA 时只保留一个拥有全局输入的 Rill 实例。具体步骤见 release-qa-checklist.md。
