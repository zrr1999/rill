# Rill UI 方向：内容检索与原生 macOS 工作站

设计基准为 Apple Human Interface Guidelines；Raycast 只用于快捷面板的搜索、键盘操作与内容预览参考。

macOS 26 是最低版本；实现以现有 SwiftUI/AppKit 界面为基础，保留已有效的结构和使用习惯，系统导航与必要浮层采用 Liquid Glass。正文、预览和编辑内容保持稳定不透明。品牌图标及文档站框架保持既有设计。

界面保留主要入口同组置顶、合并快捷面板与待发编辑，以及现有录音浮窗。复用现有状态所有者，不增加内容副本或数据迁移。

## 界面语言

App 语言统一控制主窗口、菜单栏、独立面板、App 自建确认框和辅助功能文案。首次启动按系统首选语言顺序选择已支持的中文或英文；已保存的明确选择优先。相对时间和日期格式使用 App 语言，保留系统地区、日历、数字格式、时区与小时制偏好。错误状态保留原因或可延迟解析的展示资源，切换语言后已有提示同步更新。用户正文、自定义名称、文件名及原始解析诊断保留原值；技术详情前提供本地化摘要。内建记录集和待发容器按稳定 ID 与默认名称显示译名，用户重命名后显示用户名称，切换语言不改写存储内容。计数通过 String Catalog 复数规则处理。

## 信息架构

语音输入是产品主线，工作流是可复用的辅助配置；用户不需要先理解工作流就能完成语音输入。

主窗口围绕“找回和复用内容”组织，默认进入全部记录。侧栏顶部同一组依次是全部记录、活动、工作流，之后是记录集，底部设置入口在同一窗口切换为设置侧栏。听写循环仍由字幕浮层、菜单栏与快捷面板承担。

- 全部记录是 RecordStore 的去重视图，选择该入口不隐式选中第一个集合。
- 记录采用导航、列表、详情分栏。列表展示摘要、来源与时间；详情优先展示内容与复制，集合归属与元数据放在详情披露中。集合策略进入集合设置，采集与投递规则在独立管理入口中。
- 内容区不足 700pt 时在列表与详情之间切换；默认主窗口仍为 960×720，支持调整分栏宽度。
- 主窗口首次准备不足时呈现可跳过的准备面板，只展示 VoiceSetupReadiness 的缺失条件；关闭后本次会话保留工具栏恢复入口，不因异步刷新反复弹出。
- 活动页突出待处理选择、失败恢复和进行中状态；成功运行使用紧凑行，展开后保留完整回执、纠错、隐私预览及失败录音恢复。精确阶段耗时只显示已记录的数据，旧数据的时间区间不推算为精确时间。
- 工作流采用列表与说明详情，依次展示用途、触发方式、输出和启用状态，处理步骤按需展开。外部 TOML 编辑、导入、复制、恢复预设与删除仍沿用原有行为。

运行行只保留一份标题、状态和时间；收起时显示正文预览，展开时原位显示正文与紧凑的阶段耗时。键盘与辅助功能焦点落在展开按钮上，不包住整块详情。

单次运行的“执行详情与诊断”按 run ID 查询最近 20 条已清洗事件，失败操作直接展开当前运行的诊断。默认显示警告与错误，其他日志通过“显示全部”查看；每条事件用一行摘要，技术字段按需展开。录音长度来自音频，识别与润色 API 耗时来自单调时钟；未计时、旧记录缺失或未运行的步骤不补估值，失败、取消和回退保留实际消耗的调用时间。

## 统一搜索与导航

主窗口 `⌘F` 和工具栏入口使用同一搜索浮层。首次和重复唤起都聚焦同一 AppKit `NSSearchField`，重复唤起保留查询与结果选择。方向键、回车和 Esc 分别移动选择、确认和关闭浮层；后台页面不抢焦点。页面不再提供第二套文字搜索框，置顶、来源与类型仍属于页面筛选。

结果依次为记录、记录集、运行历史、工作流、设置、页面。Record 通过现有 RecordStore.query 查询完整可搜索内容，扫描空批次并支持继续加载；运行历史沿用既有浏览服务与隐私预览权限。两类异步查询独立失败，过期查询不能更新新结果，搜索关闭即取消展示。

搜索选中 Record 后调用统一定位动作：进入全部记录、清除冲突筛选、刷新目录、选中记录并聚焦详情。记录被删除时显示不可用状态。快捷面板“在记录中显示”复用同一入口。搜索选中记录不会粘贴。

普通页面路由由 MainShell 恢复侧栏键盘焦点；typed Record / History 目的地由详情页持有目标焦点。Settings 深链由同一主窗口内的 SettingsView 定位分区与控件。

鼠标 List 选择在切换路由前取得侧栏响应者，选择回调返回时侧栏仍持有焦点。后续修复覆盖 mouse tracking 的交互模式和主 RunLoop 的 default mode，按路由身份校验补偿；不能抢走用户新取得的详情或搜索焦点。不要仅靠 `Task.yield()`，也不要只等待 default mode 后才恢复侧栏。键盘焦点修复不挪动用户独立设置的 VoiceOver 焦点。

修改导航或焦点桥接时，覆盖“全部记录 → 活动 → 工作流 → 记录集”的方向键、 List selection、快速路由、精确 Record / History 详情的辅助功能焦点及设置深链。对应回归见 [MainShellFocusIntegrationTests](../Tests/RillUITests/MainShellFocusIntegrationTests.swift)。

## 主窗口中的设置

设置与主窗口共用同一个窗口、AppModel、持久化协调和保存失败状态，不创建第二套服务、存储或 Settings scene。`⌘,`、App 菜单“设置…”、菜单栏和设置深链都先进入设置模式，再打开或激活主窗口。

| 分区 | 内容 |
| --- | --- |
| 常规 | 界面语言 |
| 输入 | Fn 工作流、语音助手就绪与唤醒监听、剪贴板捕获、面板快捷键 |
| 模型服务 → 语音识别 | 本地识别模型、下载、启用与常驻资源 |
| 模型服务 → 分类与评分 | Jev / Clef 配置、临时凭据与可选分类功能 |
| 模型服务 → 语言模型 | 所有工作流共用的连接、模型与 Key |
| 模型服务 → 语音合成 | 本地合成模型与系统语音回退 |
| 词汇与记忆 | 词汇映射、上下文纠错、长期记忆管理 |
| 隐私 | 系统权限、敏感应用和预览策略 |
| 数据 | 留存、清理、恢复与诊断 |

进入设置不改变当前页面、记录集、记录选择或活动范围。侧栏顶部的“返回”（`⌘[`）回到进入前的页面和选择，并丢弃比较返回意图；“返回比较”仍按原按钮恢复比较。全部记录、活动、工作流、记录集和全局搜索中的内容定位也会离开设置，但保留上次的设置分区。关闭主窗口同样丢弃比较返回意图。

分类模型在“模型服务”的“分类与评分”模块选择 Jev 或 Cloudflare Clef；相应 API Key / Token 在此配置，仅保留到退出 App；候选比较弹窗提供直达设置的入口，继续要求发送前预览和确认。全局搜索 Jev、TypeSafe 定位“分类与评分”模块，LLM API 定位“语言模型”模块。

六个页面使用同一主窗口侧栏和分组表单；侧栏只有一个“模型服务”入口，页面内按语音识别、分类与评分、语言模型、语音合成分为四个可展开模块。模块标题只使用当前界面语言，不并列中英文。首次进入显示四个折叠模块，服务深链展开并定位对应模块。模型标识与常驻选项按需展开。切换页面保留当前表单草稿，隐藏页面不接受键盘或辅助功能焦点。窗口标题保持应用名，页面名显示为副标题。

设置深链携带具体设置项，映射到分区并定位。再次进入保留本次运行中的最后分区。

## 统一快捷面板与待发编辑

快捷面板与待发编辑共用一个非激活原生页面，顶部通过“待发 / 记录集”切换。记录集模式保留剪贴板与其他记录集选择、搜索、结果、预览、复制、加入待发和明确输出。待发模式复用现有列表及 NSTextView；正文、真实保存状态和发送优先，修改差异及容器策略次级。模式切换不清空查询、选择、滚动位置、编辑和撤销历史，不触发输出；中文组合输入优先。记录集模式 Return / ⌘1…9 输出；待发编辑 Return 换行、⌘Return 显式发送。

默认 Cmd+Cmd 唤出统一面板，首次进入记录集，此后恢复本次运行中上次选择的模式。再次按快捷键、Esc、关闭按钮或完成编辑会关闭面板，不留下常驻条；切换到其他窗口时也会关闭。组合输入先由输入法处理，附加确认框先于面板关闭。菜单栏和记录页保留待发入口。待发来源开关继续复用既有语音和剪贴板设置；开启来源、恢复设置和新内容到达均不弹出面板。关闭面板不停止收集，也不清空草稿。显式发送后关闭面板，必要的输出确认与文件拖放仍使用临时窗口。

面板在当前鼠标所在屏幕的可用区域居中，默认 668×468pt，并随正文文字大小在上下限内缩放；屏幕不足时缩小并保留 12pt 边距。浏览、编辑、异步到达和输出提示不会重新布局窗口。展开淡入为 100ms，减少动态效果时直接显示。页面顺序为模式切换与关闭、固定高度状态行、列表与正文、固定底部操作。确认详情、来源设置和修改差异单独打开，不挤动主操作区。录音浮窗继续独立呈现。左栏首选 194pt，并随正文文字大小在上下限内缩放。页面使用 Liquid Glass 底色；导航侧栏、模式轨道、选中模式与底部操作使用同一玻璃语言，减少透明度或提高对比度时回落到不透明控件背景。正文区保持不透明。侧栏与正文内缩 8pt，由 `ConcentricRectangle` 跟随外框计算圆角；每个模式使用独立的 `GlassEffectContainer`，避免隐藏模式参与当前玻璃合成。列表用单行标题与来源分层，标题、正文和辅助文字使用语义字号。完成编辑保持轻量，复制使用原生 `.glass`，发送使用强调色 `.glassProminent`；模式选择通过 `glassEffectID` 平滑切换，并尊重减少动态效果。控件样式调整不替换 NSTextView、原生列表选择或既有焦点与撤销路径。再次从外部应用唤起时，在面板激活之前捕获目标并通过现有身份校验；模式切换不改投，重开后重新校验目标。保存失败保留编辑内容和重试入口。

## 环境层与视觉规则

主窗口工具栏使用原生 `ToolbarSpacer` 区分上下文操作与全局搜索。草稿入口、设置、复制与工作流操作采用 `.glass`，明确执行或输出使用 `.glassProminent`。草稿入口位于记录分栏上方；`safeAreaBar` 固定记录详情操作、全局搜索输入、设置标题和工作流底部操作；滚动内容使用 `.scrollEdgeEffectStyle(.soft)` 在控件边缘自然退后。设置保留原生分组表单，活动页以更清晰的标题层级区分历史摘要和正文。

录音浮层与悬浮工作区共用 `RillGlass` 的材质和辅助功能处理：常态为原生 regular Liquid Glass，减少透明度或增强对比度时为不透明系统控件背景。玻璃表面使用系统自身的光照和深度，不叠加自制半透明染色、外边框或阴影；Esc 提示使用同一玻璃胶囊。录音尺寸、时限操作和按键行为保持稳定。

- 紧凑字幕保持 248 × 48pt，为临近录音时限的继续按钮预留空间；计时与 Esc 键盘提示完整显示，倒计时出现时不改变窗口宽度。
- 快捷面板保留回车粘贴、复制、置顶、⌘1…9、Esc 逐层关闭。统一悬浮页中列表和预览始终左右分栏。
- 目标应用名称来自投递控制器同一目标解析路径，目标激活与退出时更新提示；实际投递仍经过现有焦点恢复和身份校验。
- 主窗口复制复用现有 RecordReuseSubject 通道，根据实际复制结果反馈，不调用集合消费投递。
- 使用系统字体、强调色、语义背景和原生选择色。现有 4/8/12/16/20/24pt 间距与 RillRadius 继续复用；卡片用于需要行动的事项。
- 原生控件和转场优先；自定义状态变化不阻塞输入。分别适配减少动态效果、减少透明度、提高对比度和区分不含颜色；减少透明度时字幕与快捷面板使用不透明系统背景。主窗口侧栏使用系统 sidebar 列表样式。空态使用 `ContentUnavailableView`。复制与发送使用系统触感反馈，状态符号使用 SF Symbols 替换动效，计数使用数字转场。
- 文案走 L10n 双语表；SF Symbols 复用 RillSystemSymbol。保存和复制反馈以真实结果为准。

应用与菜单栏的图标语言、状态区分和源文件维护见 [图标设计](icon-design.md)。功能图标继续使用 `RillSystemSymbol`；品牌标记以 `Resources/AppIcon` 中的 SVG 为源。菜单栏就绪态使用单色 template PDF，有记录时显示圆点；录音、权限和临时采集状态沿用系统符号。

### 菜单栏选项

菜单栏以分组原生菜单为基准：顶部只保留运行状态、Fn 提示或需要处理的问题；接着是打开待发区、全部记录、活动；常用操作组包含复制上次转写、语音输入、剪贴板和运行工作流；底部保留主窗口、唯一的设置入口、关于与退出。操作项统一显示 SF Symbols，选择项使用系统勾选状态，维持原生菜单的键盘导航。

语音输入子菜单集中录音方式与输出去向；“先收进待发区”沿用现有待发收集语义。剪贴板子菜单包含捕获开关、忽略下一次复制、输出下一项和可复用记录数，关闭、开启中和一次性忽略的状态仍在首层标题中可见。文字风格、切换式录音和全部手动工作流归入运行工作流，选择条目仍执行原有工作流；界面语言位于设置的常规分区。失败入口打开活动，准备未完成和存储异常保留各自的修复入口。

后续可逐项评估控制面板中的直接开关或选项摘要，前提是有明确的使用收益，并验证键盘、焦点和辅助功能；当前继续使用原生菜单，不整体替换为浮动控制面板。

## 验证边界

### 目标流程与布局

```text
主窗口（默认 960 × 720）
┌ 侧栏 ────────┬ 记录列表 ─────────┬ 内容 ────────────────┐
│ 全部记录      │ 摘要              │ 正文 / 图片 / 文件     │
│ 活动          │ 来源 · 时间        │ 复制                  │
│ 工作流        │ 筛选：置顶/来源/类型│ 集合归属、元数据       │
│ 记录集        │                  │                      │
└─────────────┴─────────────────┴─────────────────────┘
⌘F → 分组结果 → 定位具体记录 → 预览 → 复制
快捷面板 → 本地候选 → 比较预览 → 显式发送 → 选择候选 → 显式粘贴
                        ↓ 配置/修复
              设置具体项 → 返回比较 → 新预览 → 显式发送
```

不足 700pt 的记录内容区只显示列表或详情，返回保留选择与滚动位置；无记录时只呈现一个空态。列表保留有效选择，内容更新不抢焦点。详情长文本可选择、滚动，图片按可用空间适配，文件不可用时呈现原因；文件预览不能改变原始 payload 或触发外部打开。

全局搜索和快捷面板共用字面优先查询：完整字面扫描没有结果才启用近似/拼音匹配。同一查询的后续页保留匹配模式和目录版本；版本变化重新查询，快速输入取消旧任务。页面文字搜索不触发云服务。本地语义结果与 分类模型比较继续作为明确标识的可选入口。

设置导航采用“分区 → 章节 → 具体控件”，搜索与错误动作使用相同映射。章节的键盘与辅助功能焦点落在可展开/收起的标题上，焦点框不包含展开后的表单内容。分类模型凭据只存在于本次运行，共享配置状态，但候选发送与润色判断是独立授权：保存 Key 不启用开关；清除 Key 关闭润色并使进行中的旧授权失效；无效替换保留原配置并报告错误。

比较离开弹窗时只保留内存中的查询、筛选、选择与候选 ID，不保存预览正文、凭据或已确认授权。返回按钮重新读取候选并校验当前隐私、目录和有效期；删除/隐私变化要显示原因。快捷面板等待退场动画和旧比较弹窗结束后重建预览；期间晚到的复制或输出失败不重新打开旧面板。关闭设置或取消返回清理这次意图。网络/限流错误允许用户重新准备预览，再次发送必须确认。

### 持续验收范围

| 优先级 | 页面与改动 | 完成标准 |
| --- | --- | --- |
| P1 | 记录详情收敛正文、复制与次级信息；统一搜索只保留一个高频入口 | 文本、图片、文件、长内容、空结果都可完成搜索到复用；不重复空态 |
| P1 | 活动页顶部仅展示进行中、阻塞与可恢复失败 | 成功记录紧凑；每个异常有原因和可执行入口；耗时来自当前运行真实计时 |
| P2 | 设置按职责导航，四类模型服务各自独立成页 | ⌘,、搜索和错误入口定位同一控件；保存失败可见且不谎报成功 |
| P2 | 工作流详情先解释用途、触发方式和输出 | 启用状态可读，编辑/导入/恢复移入次级操作，不暗示可视化编辑能力 |
| P2 | 菜单栏、字幕与快捷面板统一状态和操作层级 | 提示与实际投递目标一致；正常状态安静，错误可恢复，不延迟输入输出 |
| P3 | 首次使用与词汇/记忆管理整理 | 只展示当前缺失条件；区分显式映射与学习内容，保留查看来源和删除入口 |

### 状态与交互验收矩阵

| 范围 | 必须覆盖 |
| --- | --- |
| 搜索 | 字面优先、拼音/近似兜底、跨空批次分页、快速输入取消、版本变化重查、单源失败、已删除结果 |
| Jev | 初次未配置、有效替换、无效替换、清除中请求、默认关闭润色、隐私撤销、失败回退、退出清理 |
| 设置返回 | 精确控件定位、上下文保留、关闭清理、重新预览、明确二次确认；不得自动发送或粘贴 |
| 布局 | 中英文、深浅色、960×720 与紧凑窗口、长文本、文本/图片/文件、空态、失败态 |
| 键盘 | 首次及重复 ⌘F、⌘,、方向键、Return、Esc、⌘1…9；中文组合输入不误提交 |
| 辅助功能 | VoiceOver 标题与控件顺序、选择播报、焦点恢复；减少动态效果、减少透明度、提高对比度分别验证 |

模型与查询测试覆盖分页、取消、失效记录、主窗口设置导航和失败结果；原生 AppKit 测试覆盖焦点。UIRenderEvidenceTests 与 RecordQuickPanelRenderTests 使用临时样例数据导出渲染证据。

自动化与快照不能替代真实 Fn、IME 组合输入、跨应用粘贴、VoiceOver、多显示器和 macOS 26 交互验收。QA 时只保留一个拥有全局输入的 Rill 实例。具体步骤见 release-qa-checklist.md。
