# 语音输入

## 听写

默认“语音识别”工作流使用 Fn：按住说话，松开后录音浮窗立即收起，后台继续补录 500 毫秒，保留完整句尾。
这段时间内再次按下 Fn 会恢复浮窗并继续同一次录音，下次松开后重新计算 500 毫秒。
补录期间仍可按 Esc 取消；停止提示音在麦克风关闭后播放，避免录进音频。
切换式录音仍在第二次按下时结束；Esc 取消、权限撤销和退出会立即停止采集。
识别在本机运行，随后应用词汇规则，将最终文字保存到语音输入记录，再输入当前应用。
在“设置 → 输入”逐项选择输出；保存记录自动启用，直接输入和加入待发区可以分别关闭。
启用“加入待发区”会把结果加入语音 Queue；只想先收集时关闭直接输入，可以在
[待发区](records.md#待发区与编辑)自由编辑和核对识别差异，再发送所选项。
无需编辑时，聚焦目标后按 ⌘⇧V 依次输出，具体规则见[连续输出](records.md#连续输出)。

Fn、界面按钮和菜单栏启动的录音，在麦克风采集就绪后播放短促的开始音，正常停止采集后
播放不同的结束音；取消或启动失败不会播放结束音。切换录音模式使用相同提示。
音量跟随 macOS 输出设置，静音时听不到提示。唤醒词仍只播放一次开始提示。

Rill 提供本地 Qwen3-ASR 0.6B 和可选的 1.7B 模型。在“设置 → 模型服务 → 语音识别 · ASR”准备并启用模型。
更换模型后，以界面中的就绪状态为准。流式文字是预览，最终输出以完整录音识别的结果为准。

识别后没有文字会回到待命，不调用润色，不新增运行记录或显示失败；录音时长本身
不决定是否忽略，因此很短但包含内容的语音仍会正常处理。麦克风、识别服务等实际错误
仍会提示。

“活动”页显示进行中、待处理选择、最近结果和运行历史。识别完成而输出失败时，
先从“全部记录”取回文字，再检查目标输入框和辅助功能权限。

## 智能整理

1. 在“设置 → 模型服务 → 语言模型 · LLM”配置 OpenAI / DeepSeek / 已验证兼容服务的地址、模型和 API Key。
2. 使用配置验证动作检查服务，确认所需云端处理授权。
3. 在“工作流”启用“智能整理”。它与“语音识别”共用 Fn，启用一个会停用另一个。
4. 按 Fn 录音。识别仍在本机完成，整理步骤把文字和要求发送到配置的服务。

智能整理修正明显错字、标点和段落，不把转写里的问题当成需要回答的指令。
LLM Key 保存在 macOS Keychain。兼容服务的参数和可用模型由该服务决定，
更换服务预设会设置相应地址并清除 Key；更换模型不会改变服务地址。
所有工作流共用这一份 LLM 连接；每个 LLM 步骤显式声明 `none`、`low` 或 `high`，
由服务适配器转换为已验证的推理参数。工作流不指定模型；不支持的档位会显示能力错误。
运行准入时冻结所需服务，设置变更用于后续运行。

可恢复的网络、限流或超时错误可能保留整理前文字；活动中会显示整理跳过。
取消、隐私阻止、认证等不可继续的错误会停止投递，不会默默换用另一个云服务。

### 可选的分类模型润色判断

在“设置 → 模型服务 → 分类与评分 · Decision”选择 Jev / Clef / Clef Flash 并暂存相应 Key 或 Token，然后单独开启“用分类模型判断是否需要润色”。
Key 与[记录候选比较](records.md#用分类模型比较候选)共用，只保留到退出 App；
保存 Key 不会自动开启润色判断，清除 Key 会关闭开关并撤销旧授权。

开启后，支持的智能整理步骤先向分类模型发送转写文字和润色要求。明确无需修改时，
原文仍会保存并输出；不确定或判断失败时继续原有 LLM 整理。
使用屏幕或记忆参考的运行仍直接进入整理，不把这些参考发送给分类模型。

这是可选的云端判断，可能产生服务用量；它不是离线优化或纠错正确性的保证。

## 语音助手

语音助手默认停用。在模型服务的 LLM 页配置统一连接，在 ASR、TTS 页准备需要的语音资源，
授权后在“工作流”启用，再到“设置 → 输入”开启唤醒监听并修改唤醒短语。默认短语为“Hey Rill”。

开启监听会持续使用本地麦克风；关闭监听即可停止。助手生成回答，先保存为记录再朗读。
优先使用可用的本地语音合成，必要时回退到系统语音。

## 改善专有词

识别时需要提示名称可使用热词；稳定、可预测的错词替换可使用映射词。
从识别历史提出纠正后，需要确认再加入词库。具体步骤见[词汇与记忆](vocabulary-memory.md)。

### 可选的分类模型热词挑选

在“设置 → 模型服务 → 分类与评分 · Decision”暂存所选分类服务的 Key 或 Token，再单独开启“智能挑选热词”。
这是默认关闭的实验功能；保存 Key 不会开启它，清除 Key 会关闭开关并撤销旧授权，
Key 和开关都只保留到退出 App。

启用后会向所选分类服务发送作用域匹配的已有候选热词、应用与工作流名称及已授权选区。
选区超过 1,800 UTF-8 字节时整段省略；不发送音频、剪贴板、屏幕或历史记录。
录音不等待网络：新上下文首次沿用规则挑词，后台排序供后续相同上下文的最终识别使用。
实时字幕不变，人工优先级保留；识别收益尚待获授权录音的对照验收。
