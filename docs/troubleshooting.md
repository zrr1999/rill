# 排查问题

先在“活动”查看具体运行的失败原因；有文字但未能输入时，先从“全部记录”找回内容。诊断入口是“设置 → 数据 → 诊断”，也可以用 ⌘F 搜索“诊断”。

| 现象 | 检查与恢复 |
| --- | --- |
| Fn 没有反应 | 检查输入监控权限、当前启用的 Fn 工作流、录音触发方式和语音设置清单 |
| 无法开始录音 | 检查麦克风授权、输入设备和活动中的阻塞原因 |
| 模型未就绪 | 联网完成模型准备，确认所选模型已启用；按界面错误恢复 |
| 识别完成但未输入 | 确认辅助功能权限和目标输入框；从记录中复制文字，不反复重放已完成的输出 |
| 智能整理失败 | 在“模型服务 → 语言模型”检查地址、模型和 Key，并使用配置验证 |
| 记录搜索不到 | 清除置顶、来源或类型筛选；试用关键词、完整拼音；检查采集与留存设置 |
| 本地语义搜索不可用 | 在快捷面板主动准备搜索模型，等待完成后重新搜索 |
| 文件预览失效 | 核对原文件是否移动、删除或失去读取权限；记录不含文件副本 |
| 工作流不运行 | 检查是否启用、TOML 错误、触发冲突、输入种类及所需服务 |
| 设置未保存 | 保留失败提示，按提示重试；不要把仍显示的编辑值当作已经写入磁盘 |

## 按录音后的状态恢复

1. **仍在处理中**：查看“活动”中本次运行，等待识别或整理结束；录音浮窗收起后仍可能继续处理。
2. **已经保存但输出失败**：在“全部记录”复制已保存文字，核对目标输入框和辅助功能权限。先确认目标是否已收到部分内容，避免重复输入。
3. **回到待命且没有运行记录**：无内容的识别不会新增记录。重新试一句清晰的话；如果无法采集，再检查麦克风权限和输入设备。
4. **存在明确错误**：保留该次运行的错误提示，按上表对应项目恢复。缺失的耗时不表示处理耗时为零。

## 分类模型比较与润色判断

分类模型的 Key / Token 在“模型服务 → 分类与评分”中配置。全局搜索 Jev API 或润色判断，可直接定位对应控件。它与 LLM Key 不同，不会写入 Keychain。

| 提示 | 恢复动作 |
| --- | --- |
| 缺少 Key 或认证失败 | 进入 Key 设置，检查所选 TypeSafe / Cloudflare 服务的账户和凭据；返回比较后重新核对预览 |
| 隐私阻止 | 打开隐私设置检查规则；未知或敏感来源可能不允许发送 |
| 预览过期、记录或授权变化 | 重新准备预览；已删除候选不可继续使用 |
| 网络、限流或无效响应 | 确认网络和账户后手动重新准备预览，再决定是否发送 |
| 上一请求仍在结束 | 等待前一请求结束后重新准备，避免重复提交 |

返回比较、保存 Key、重新准备预览都不发送请求。点击发送才提交；失败后的重试也需要新确认，已发送请求可能计费。

润色判断默认关闭，暂存 Key 后还需显式开启。清除 Key 会关闭开关；再次配置 Key 不会自动重新开启。判断不确定或服务失败时继续原有整理步骤。

## 查看证据与反馈

运行详情显示步骤、结果和已记录的耗时；旧记录或未测量步骤的缺失数据不表示零耗时。关联诊断用于解释该次运行，无法据此证明另一运行的状态。

普通问题通过 [GitHub Issues](https://github.com/zrr1999/rill/issues)反馈，说明版本、 macOS 版本、操作步骤、预期和实际结果。附日志或截图前去掉私人正文、文件路径和凭据。安全问题使用[安全报告渠道](../SECURITY.md)。
