# 记录与搜索

## 采集和浏览

剪贴板采集默认关闭。在“设置 → 输入”或菜单栏主动开启后，Rill 才会保存允许采集的
文本、图片和文件引用。它不会接管原生 ⌘C / ⌘V，也不补录关闭期间的变化。

“全部记录”显示仍被保留的内容，不要求先选一个记录集。同一记录可属于多个记录集。
再次采集相同正文时，先比内容哈希，再核对正文；命中后复用最早的那条记录，来源和
创建时间保持不变。目标记录集里还没有它，就补上成员关系；已经消费掉的成员会重新
变为活跃，并回到该记录集列表前面。编辑或替换产生的派生记录仍单独保存。
剪贴板采集会计入复制次数，第一次就是 1；成功粘贴或输入到应用会计入使用次数。
从 Rill 复制回系统剪贴板只增加复制次数。
列表选择记录后，在详情查看正文、来源和时间；复制操作按实际结果反馈。

图片可查看大图。文件记录显示缩略图、类型和大小，并可使用 macOS Quick Look 预览。
文件引用读取原路径的当前文件，不保存副本；文件移动、删除或不可读时会提示。
打开预览、搜索和选择结果都不会自动粘贴。

## 搜索

主窗口按 ⌘F，同时搜索记录、记录集、运行历史、工作流、设置和页面。
选择记录结果会进入全部记录并定位内容；若记录已删除，会显示不可用。

全局搜索与快捷面板使用相同的本地匹配规则：

1. 先查正文、文件名、来源和标签中的关键词。
2. 完整扫描没有字面结果时，再尝试英文缩写、少量拼写错误、中文全拼或至少三个字母的拼音首字母，
   例如 jiantieban 或 jtb。
3. 更多结果延续当前匹配模式；查询或记录变化时重新检索。

字面结果优先。网址、绝对路径和带长数字的单个编号不做模糊纠错。
搜索无需模型下载或云端调用。置顶、来源和类型是快捷面板的筛选条件；
主窗口从全局结果定位具体记录时会清除阻挡该记录的页面筛选。

## 快捷面板

从菜单栏或配置的快捷键打开面板，输入关键词，用方向键选择，再按 Return 粘贴。
⌘1…9 可直接选取对应结果投递；复制和置顶使用显示的动作。
Esc 先退出预览或弹窗，再关闭面板。中文输入法组合输入期间先完成选词。

粘贴前核对内容与底部目标应用提示。图片和文件需要目标 App 支持对应类型；
文件引用还需原文件可访问。失败或取消不会把记录集成员标记为已消费。

点击“预览”查看内容，预览会跟随选择。较宽面板可左右显示结果与预览，
窄面板在下方显示预览。

## 按含义补充

快捷面板的“按含义补充”适合用一句话描述要找的内容。首次需要主动下载约 1.2 GB
的本地搜索模型；查询和记录不上传。语义候选单独列出，保留关键词结果与当前选择，
来源、类型和置顶筛选继续生效。

第一次准备记录可能较慢，后续查询可复用内存中的向量。长记录只覆盖部分内容，
图片不参与语义检索；候选次序不是正确性概率，使用前仍需核对正文。

## 用 Jev 比较候选

1. 在有本地结果的面板点击“用 Jev 比较…”。
2. 查看查询和最多 10 条候选文字片段或文件名。
3. 未配置时点击“配置 Jev API…”：设置会定位 TypeSafe Key 输入框。
4. 暂存 Key 后点击“返回候选比较”。查询、筛选和有效选择保留，预览重新读取并校验。
5. 核对新预览后主动点击发送。选择评分结果只定位记录；粘贴仍须自己操作。

比较使用 TypeSafe 的 Jev 付费评分。每条候选最多发送 1,800 UTF-8 字节，截短会标明；
不发送图片、引用文件正文、标签或来源应用。敏感来源及当前隐私策略可阻止请求。

Key 与语音润色判断共用，只保留在本次 App 会话中。配置或返回比较都不会自动发送；
关闭设置或“取消返回”会丢弃返回意图。记录被删除、授权变化、预览过期时需重新准备。
网络或限流失败不会自动重试；已发出的请求仍可能计费。

## 连续输出

按 **⌘⇧V** 输出下一项。这个快捷键可在“设置 → 输入”修改，并检查与面板快捷键的冲突。
原生 ⌘C / ⌘V 和显式复制操作保持原有用途。

待输出内容由独立容器保存：剪贴板使用 Stack，语音收集模式使用 Queue。
直接输入成功的语音不会再次排队。组间优先选择含最新未消费输入的容器，
组内按 Stack 最新优先或 Queue 最早优先输出。待用内容没有时间窗口，重启后仍可继续。
Set 用于手动取用，同一记录只加入一次，使用后保留。

在记录页的“待输出容器”菜单中，可以启用旧容器、加入历史记录或创建 Set。
若复制内容已存入历史但未能加入容器，Rill 会提示失败并保留记录；选中该记录后，
可通过同一菜单的“加入”重试，无需再次复制。
迁移的旧容器默认关闭，新默认容器从空开始；Raycast 历史不会自动加入。

连续输出不写入系统通用剪贴板。文本通过辅助功能或 Unicode 键盘事件插入；
无法验证结果时，需要确认“已插入”后才推进，或选择重试并重新聚焦目标。
图片和文件通过浮层拖到目标应用，仅复制原文件。失败、取消及部分输出保留条目；
目标应用的支持情况以实际交互为准，Rill 不自动提交表单或发送消息。

## 待发区与编辑

从菜单栏的“打开待发区”，或记录页的“待输出容器”菜单进入。左侧是已有待发项，
右侧是所选文字的原生编辑器，支持选区替换、换行、复制粘贴和撤销。
输入文字只修改当前草稿；点击“新建”才增加一项。新复制或新识别的内容不会切走当前选择。

在“设置 → 输入”把语音输出方式设为“先收进待发区”，识别结果会先进入语音 Queue，
可以检查、修改后发送。此方式可选；直接输入仍沿用原来的行为。
面板中的“录音新建”单次收集新条目，不改变默认输出方式；“在此听写”把录音绑定到
当前草稿及开始录音时的选区。录音后继续修改、切换条目或离开编辑器时，结果保留为
待应用建议，由你决定插入位置。识别中的预览不会改写正在编辑的正文。

编辑器内 Return 换行，⌘Return 发送所选项；左侧列表获得焦点时 Return 发送所选项。
中文输入法的组合输入和选词优先处理。Esc 先交给输入法，再退出编辑焦点，最后关闭面板。
关闭会保留草稿，重新打开或重启可继续；保存失败时文字仍留在编辑器中，并显示重试提示。
“移除”丢弃该待发项及其修改，原始历史记录仍保留。

“查看修改差异”可对比识别原文或进入草稿时的文字：删除带删除线，新增带下划线。
这能帮助检查错词，但改写、补充和删节不一定是识别错误，也不会自动写入词库。
发送修改稿会生成新记录，原记录保持不变，待发顺序也不改变。

面板会记住打开前可读取的目标输入框及选区。目标或选区变化时保留内容，不自动改投其他输入框。
从 Rill 主窗口打开、或无法确认原目标时，先点击发送准备所选项，再聚焦目标并按输出快捷键。
发送只插入文字，不替你提交表单或发送聊天消息；无法验证插入时仍需确认结果。

## 记录集与删除

记录集用于组织内容；新建记录集默认使用 List。旧工作流的记录集路由继续保留以下预设，
它们不参与“输出下一项”的调度：

| 预设 | 使用方式 |
| --- | --- |
| Stack | 最新优先，成功投递后移出该记录集 |
| Queue | 最旧优先，成功投递后移出该记录集 |
| List | 手动选取，投递后保留 |

选取顺序与消费策略可分别在集合设置中调整，采集与投递规则有独立管理入口。
移出记录集只移除成员关系；明确删除记录会删除其内容和全部成员关系。
按保留期清理及永久删除前，先核对界面列出的影响范围，见[隐私与数据](privacy-data.md)。
