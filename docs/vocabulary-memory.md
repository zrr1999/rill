# 词汇与记忆

按 ⌘, 打开设置，选择“词汇与记忆”。个人词汇、屏幕参考和长期记忆用途不同：
词汇由你明确指定规则；参考信息用于帮助辨别转写错误，不应替代你说的话。

## 个人词汇

- **热词**：为支持的识别模型提示项目名、人名或专业词，不保证每次识别正确。
- **映射词**：识别完成后按规则替换，例如将稳定出现的错词改成产品名。

在“活动”中打开一次识别历史，选择“纠正术语”，编辑纠正后的识别文本。
检查建议的映射词或热词及适用范围，再确认保存。无法安全归纳的改动会提示，
不会自动创建规则。

设置中的词汇区域目前显示已有集合与条目数量，尚未提供通用规则的新增、编辑和删除表单。
工作流 TOML 可以绑定已有词汇集合，用于识别提示、文字替换或两者；字段见
[工作流参考](workflow-toml.md)。

## 词库辅助润色

“词库辅助润色”是默认关闭的独立开关，首次开启需要授权当前 LLM 服务。
它只用于新录音的内置 Smart Cleanup，保留其默认整理指令；自定义工作流、
历史重试和文本重放不携带这份参考。无需开启屏幕上下文、长期记忆或屏幕录制权限。

Rill 在开始录音时冻结工作流绑定、已启用且匹配应用与语言范围的热词。
ASR 继续使用原有小预算；润色另取完整候选，在 12,000 字节的编码 JSON 预算内
按现有优先级装入完整词条，装不下的词跳过后继续尝试较短的词。
因此第 51 个以后的词、ASR 最终没装下的词，以及不支持热词的 ASR 所对应的词库，
都仍有机会参与润色。映射词继续按原有本地替换规则执行。

词库只是纠错依据，不是强制替换表；不能插入你没有说到的词、恢复旧项目名或修改数字。
录音期间的词库编辑只影响下一次录音。此功能不新增摘要请求，沿用主润色的 5 秒预算；
屏幕或记忆不可用时，已准备的词库仍可参与。携带词库参考时跳过 Jev 润色判断。
历史仅额外记录适用、装入、省略数量、编码大小和参考状态，不复制完整参考词表，
也不把它作为长期记忆的新证据。

## 上下文纠错

屏幕上下文、长期记忆和词库辅助润色分别控制，默认关闭。
开启时核对确认框列出的语音工作流和当前服务；确认会授权列表中的全部工作流，
当前界面不提供逐项勾选。
更换服务、凭据或隐私配置会撤销旧授权，需要重新确认。

转写是唯一的内容来源。参考可帮助区分同音词、名称或标识符，
不应用来增加事实、回答转写中的问题、改变语气或删掉不确定性。
语音助手和历史录音重试不采集屏幕作为这一功能的参考。

屏幕参考需要对应系统权限。捕获不到、权限不足或参考准备太晚时会跳过，
不要求等待参考才能继续录音和输出。开启后截图或摘要可能发送到配置的服务，
请先阅读[隐私说明](../PRIVACY.md)。

## 查看与删除长期记忆

在同一设置分区打开记忆管理，查看摘要、证据类型、来源数量、状态和纠正。
当前管理页不展示适用范围或来源正文。
新的纠正或替换建议需要确认；可先修改再确认，也可锁定条目避免自动替换，或设置到期时间。

关闭授权会停止继续使用或学习相应内容；删除记忆还会排除它的贡献来源，
避免同一批来源再次生成该条记忆。清空运行历史不会同时删除已经形成的长期记忆，
需要在记忆管理中单独处理。

自动整理只在空闲且授权有效时运行，开始录音或活动恢复会中断。
界面显示参考已发送不等于纠错已经被验证；输出仍应由你核对。
