# 安装与首次使用

Rill 的主要用途是把说话转成可找回、可复用的文字。先完成本地听写，再按需要开启智能整理、
剪贴板采集或语义搜索；这些可选能力不影响开始使用基本听写。

## 阅读指南与查找

本网站提供使用说明；录音、模型准备和记录搜索需要在 Mac 上的 Rill App 中进行。
手机可以阅读指南，不能在网页中启动听写。

点击页眉“查找”搜索文档，例如输入“剪贴板”，再选择结果进入对应章节。
找自己的听写内容时，请切回 Rill，按 ⌘F 搜索记录；网页搜索不会读取 App 中的记录。
窄屏可从左上角导航打开其他指南。

## 安装

需要 Apple Silicon Mac、macOS 26.0 或更高版本。首次准备语音模型需要联网；
0.6B 模型约 1.01 GB，1.7B 模型约 2.46 GB，还需预留下载缓存和可选模型空间。
模型准备完成后，本地识别无需网络。

到 [GitHub Releases](https://github.com/zrr1999/rill/releases) 查看适用版本与说明。
如有安装包，将 Rill 放入“应用程序”后打开。若尚无适用安装包，开发者可按
[贡献指南](https://github.com/zrr1999/rill/blob/main/CONTRIBUTING.md)构建。
不要把本地开发签名包当成已经通过公证的正式发行版。

运行打包后的 App 无需 Python、uv 或开发工具。macOS 拒绝打开时先核对下载来源、
版本与签名说明，不通过关闭 Gatekeeper 绕过检查。

## 第一次听写

1. 打开 Rill，按首次准备面板中的缺失条件完成设置。可稍后设置，再从工具栏“完成准备”恢复。
2. 授予麦克风、输入监控权限。要直接向其他 App 输入文字时，再授予辅助功能权限。
3. 按 ⌘, 打开设置，在“语音与模型”准备并启用本地语音模型。
4. 保持“语音识别”工作流启用，将光标放到目标 App 的文本输入框。
5. 按住 Fn 说话，松开后录音浮窗立即收起，后台继续补录 500 毫秒以保留句尾。最终文字先保存为记录，再尝试输入。
6. 到“全部记录”找回文字；到“活动”查看本次运行及失败原因。

如果 Fn 被配置成切换式录音，按设置中的触发方式结束录音。无法开始时参见
[排查问题](troubleshooting.md)，不要反复开启多个 Rill 实例。

### 确认第一次听写完成

先在一个空白文本输入框说一句容易核对的话，例如“今天测试语音输入”。
松开 Fn 后等待处理完成，核对目标输入框和“全部记录”中的文字。
录音浮窗收起只表示录音阶段结束，不代表识别或输入已完成。

- **文字已输入且记录可找回**：基本听写准备完成，可以继续下面的可选功能。
- **记录中有文字、目标中没有**：先复制这条记录，检查目标输入框和辅助功能权限；不要重复录音或重放已完成的输出。
- **记录中也没有文字**：到“活动”检查是否仍在处理或出现失败，再按[排查问题](troubleshooting.md)恢复。无内容的识别会回到待命，不新增记录。

待发胶囊可自由拖动，悬停后在旁边展开完整页面；胶囊本身不变大，也不移动。鼠标移出有收起缓冲，
编辑期间保持展开。胶囊上的关闭按钮隐藏整个悬浮窗；页面不再提供单独的收起按钮。
切换模式或展开预览不会自动输出，发送前会显示目标应用。

## 升级与卸载

Rill 尚未提供自动更新。先退出正在运行的 App，再替换为受信任的新版本。
升级前保留需要的数据；已迁移的数据不保证被旧版读取，降级前应阅读版本说明。

卸载前可在“设置 → 数据”分类清理历史和恢复数据，在“词汇与记忆”管理长期记忆，
并在 API 服务中清除凭据。退出后移除 App。

仅删除 App 不会清除模型缓存、工作流、用户数据或 Keychain 项。工作流默认位于
~/.config/rill/workflows/，备份位于 ~/.local/state/rill/workflows/；
完整位置和删除边界见 [隐私说明](../PRIVACY.md)。
