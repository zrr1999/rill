# 隐私与数据

按 ⌘, 打开设置。“隐私”管理权限、敏感应用和预览策略，“数据”管理留存、清理、恢复和诊断。

## 控制内容流向

| 功能 | 内容去向与控制 |
| --- | --- |
| 本地语音识别 | 模型准备后在本机运行，不把录音上传给云端识别 |
| 剪贴板采集 | 默认关闭；开启后只采集允许的内容，可随时暂停 |
| LLM 整理与助手 | 文字发送到配置的服务，需配置凭据并通过相应授权 |
| 本地语义搜索 | 主动下载模型后在本机运行，查询与记录不上传 |
| Jev 候选比较 | 每次预览并确认后发送展示的查询与片段/文件名 |
| Jev 润色判断 | 独立开关，开启后可发送转写与润色要求；Key 仅在本次会话保留 |
| Jev 热词挑选 | 独立实验开关，发送已有候选热词、应用与工作流名称及已授权选区；不发送音频 |
| 词库辅助润色 | 默认关闭；授权后将 Smart Cleanup 适用热词按独立预算发送给当前 LLM；历史仅额外保存参考计数和状态 |
| 屏幕与长期记忆 | 默认关闭，需单独配置和授权；可能发送截图、摘要或授权的历史材料 |

LLM Key 保存在 Keychain；Jev Key 与润色判断、热词挑选开关仅保留到退出 App。
清除 Jev Key 会关闭这两个开关，并使旧授权的响应不能继续应用；
已经发送的请求无法收回，仍可能产生服务用量。

## 敏感应用与预览

在“隐私”中配置敏感应用、云端处理及历史预览策略。
规则收紧后，记录来源和当前应用都可能阻止云端处理。比较被阻止时可以查看规则，
不要为了消除错误而无条件放宽敏感来源限制。

关闭历史正文预览会限制相应历史展示。文件预览读取原文件当前内容，
不会保存文件副本；文件权限和存在状态可能在之后发生变化。

## 留存与清理

记录正文、运行历史和长期记忆加密保存，密钥由 macOS Keychain 管理。
剪贴板与运行历史默认保留 30 天，可在“数据”调整并分类清理。

删除记录与移出记录集不同：移出只解除成员关系，删除记录会影响全部归属。
清理前核对影响范围。正在使用或已变化的数据可能要求重新检查后再确认。

失败录音恢复默认关闭；开启后最多保留 24 小时。
长期记忆有独立管理规则，清空历史不会一并删除记忆，
需要到“词汇与记忆”中处理。

## 撤销和卸载

需要停止某项功能时，关闭它的采集、监听或授权入口；需要删除已有数据时，
再执行相应分类清理。退出 App 会清除会话内 Jev 凭据。

仅删除 App 不会自动删除所有数据、模型缓存和 Keychain 项。
完整存储位置、加密边界、网络目的地和随 App 分发的说明见 [PRIVACY.md](../PRIVACY.md)。
